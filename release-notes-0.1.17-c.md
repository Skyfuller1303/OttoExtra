# OttoExtra 0.1.17-c – Alpha

8. September 2026. Bereits geschriebene Briefe später verschicken.

## Installation

Minecraft Java **1.21.11**, Java **21**, Fabric Loader **ab 0.18.1** und
Fabric API **ab 0.141.4+1.21.11**. Die bisherige OttoExtra-JAR im Clientprofil durch
**`ottoextra-0.1.17-c.jar`** ersetzen; nur eine OttoExtra-Version gleichzeitig laden.

## Brief später verschicken

1. Den noch nicht versendeten Brief in die Haupthand nehmen.
2. Per Rechtsklick öffnen und **Verschicken…** neben **Bearbeiten** wählen.
3. Empfänger auswählen und **Brief senden** drücken.

**Zurück** führt wieder zum Buch. Alternativ öffnet `/ottoextra letter send` die
Empfängerauswahl für den gehaltenen Brief. Beides funktioniert auch nach erneutem
Einloggen. Der Brief wird dabei nicht noch einmal beschrieben und ein anderer
gespeicherter Entwurf bleibt erhalten. Empfangene Briefe können nicht erneut
verschickt werden.
