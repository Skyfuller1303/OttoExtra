# Release-Validierung: 0.1.17-f

Stand: 8. September 2026. Lokale Alpha-JAR mit erweiterten Tier-Nametags und
Tierübersicht einschließlich Eseln und zusätzlichen Tierarten.

## Artefakt

- Datei: [`dist/ottoextra-0.1.17-f.jar`](../../dist/ottoextra-0.1.17-f.jar)
- Größe: 30.953.777 Bytes
- SHA-256: `609e8f4f055ae7f4c8aa8133a6971b861dc064cf5b945ee4a683191426a84396`
- Interne Version: `0.1.17-f`; Umgebung: ausschließlich `client`
- Minecraft `1.21.11`, Java `>=21`, Fabric Loader `>=0.18.1`,
  Fabric API `>=0.141.4+1.21.11`

Die remappte JAR wurde nach erfolgreicher Prüfung aus `build/libs/` nach `dist/`
kopiert. Alpha A bis E sowie `input/courier-2.1.0.jar` sind per SHA-256 unverändert.
JARs, lokale Spielprofile und Testberichte bleiben außerhalb von Git.

Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11 und
lokaler Paper-1.21.11-Welt. Die Clienttests verwenden eine isolierte Register-API.
Die Esel-Prüfung öffnet echte Widgets und speichert einen erlaubten Datensatz
einschließlich Tierart und Standort; eine produktive API wird nicht angesprochen.
Das separate ältere AnimalBreeding-Addon ist nicht Teil dieses Laufs.
Bestehende optionale-Mixin-/Testprofil-Auth- und Gradle-Deprecation-Meldungen
verhindern weder Build noch Clienttests.

Die [89 Courier-Fälle aus Alpha C](0.1.17-c.md) wurden für Alpha F nicht erneut
ausgeführt. Der geprüfte Briefcode bleibt unverändert.
