# Release-Validierung: 0.1.17-e

Stand: 8. September 2026. Lokale Alpha-JAR mit zwei Tier-Nametag-Einstellungen.

## Artefakt

- Datei: [`dist/ottoextra-0.1.17-e.jar`](../../dist/ottoextra-0.1.17-e.jar)
- Größe: 30.945.666 Bytes
- SHA-256: `d121352898134377796d41beff4dc7e7c743f65e2c5e2415d7de60dcef7a53d2`
- Interne Version: `0.1.17-e`; Umgebung: ausschließlich `client`
- Minecraft `1.21.11`, Java `>=21`, Fabric Loader `>=0.18.1`,
  Fabric API `>=0.141.4+1.21.11`

Die remappte JAR wurde nach erfolgreicher Prüfung aus `build/libs/` nach `dist/`
kopiert. Alpha A, B, C und D sowie `input/courier-2.1.0.jar` sind per SHA-256
unverändert. JARs, lokale Spielprofile und Testberichte bleiben außerhalb von Git.

Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11 und
lokaler Paper-1.21.11-Welt. Der Clienttest verwendet eine isolierte Datenquelle
für das Tierregister und erfasst die produktiv ausgegebenen Label-Befehle.
Ein produktives Tierzucht-Plugin und das ältere separate AnimalBreeding-Addon
sind nicht Teil dieses Laufs. Bestehende optionale-Mixin-/Testprofil-Auth- und
Gradle-Deprecation-Meldungen verhindern weder Build noch Clienttest.

Die [89 Courier-Fälle aus Alpha C](0.1.17-c.md) wurden für Alpha E nicht erneut
ausgeführt. Der geprüfte Briefcode bleibt unverändert. Die dort genannten
Grenzen bezüglich optionalem Modpaket und produktiven Serverdaten gelten weiter.
