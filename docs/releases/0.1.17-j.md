Die Arbeit wurde in einem getrennten Git-Worktree gebaut und getestet, damit
der zuvor gestartete Dev-Client seine bisherigen Build-Klassen behalten konnte.
Die getesteten Änderungen wurden anschließend in den Hauptarbeitsbaum übernommen.
Bei der Archivprüfung wurden ausschließlich durch den Windows-Checkout
entstandene Zeilenumbruch-Unterschiede in unveränderten Ressourcen angeglichen.
Der letzte Build enthält wieder die ursprünglichen Bytes dieser Ressourcen.

Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11,
Xaero Minimap 25.3.12, lokalem Paper 1.21.11 und unverändertem Courier 2.1.0.
Der Testclient verwendet die vorhandene Mouse-Wheelie-Korrektur für Yarn.
Die vollständige Courier-Suite, Inventar und Minimap-Bedienung wurden für den
Cache nicht erneut ausgeführt; ihre letzten Nachweise stehen in den vorigen Alphas.

Feature samt Tests und Release-Metadaten liegen in zwei getrennten Commits
ohne KI-Co-Autor-Trailer. Kein Push oder produktiver Datenbank-Schreibtest.
