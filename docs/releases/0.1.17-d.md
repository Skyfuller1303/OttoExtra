Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11 und
einem lokalen Paper-1.21.11-Testserver. Der neue Clientfall nutzt den produktiven
Toast-Renderer mit Tier-Beispieldaten; ein produktives Tierzucht-Plugin wird nicht
simuliert. Dieser gezielte Clientlauf dauerte 33 Sekunden einschließlich Start.

Die [89 Courier-Fälle aus Alpha C](0.1.17-c.md) wurden für Alpha D nicht erneut
ausgeführt. Der Archivvergleich bestätigt unveränderten Briefcode. Die dort
genannten Grenzen der Prüfung mit optionalen Mods und produktiven Serverdaten
gelten weiterhin. Bekannte Gradle-/optionale-Mixin-/Testprofil-Auth-Meldungen
verhindern weder Build noch Clienttest.
