- Größe: 30.956.731 Bytes
- SHA-256: `de3dd11d270e52f7d931daf3c5028a9f0b90367579272f02929e7cd67c93af2d`

Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11,
Xaero Minimap 25.3.12 und lokalem Paper 1.21.11. Das Testprofil enthält jetzt
auch die lokale Minimap-JAR. Der Fall setzt eine isolierte Testregion und
Hierarchie, bedient die produktive Oberfläche und stellt die Ausgangsdaten
anschließend wieder her. Ein produktiver Server wird dafür nicht verändert.

Die [Courier-Suite aus Alpha C](0.1.17-c.md) und die
[Tier-Clientfälle aus Alpha F](0.1.17-f.md) wurden für Alpha G nicht wiederholt.
Bestehende optionale-Mixin-/Testprofil-Auth- und Gradle-Deprecation-Meldungen
verhindern Build und Clienttest nicht.

Parallel wurde auf Nutzerwunsch das vorhandene Dev-Profil `run2` mit DevAuth,
Quick Play zu `ottonien.com` und aktiviertem dauerhaftem Debug-Logging gestartet.
Dieser Prozess enthält den vor den Minimap-Änderungen gestarteten Alpha-F-Code;
für die neue Minimap-Funktion ist ein Neustart erforderlich. Die manuelle
Ottonien-Sitzung wurde durch die lokalen Tests nicht beendet.
