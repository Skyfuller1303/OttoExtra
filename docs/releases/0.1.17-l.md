# Release-Validierung: 0.1.17-l

8. September 2026. Explizite Personensperren und Briefexport-Darstellung.

- Artefakt: [`dist/ottoextra-0.1.17-l.jar`](../../dist/ottoextra-0.1.17-l.jar)
- Größe: 30.986.840 Bytes; 662 Archiveinträge; ausschließlich `client`
- SHA-256: `7232cd7a3861ecb23159d14eb034f03237f374e6571745439d8ac3c0a0910455`
- Minecraft 1.21.11, Java 21; Abhängigkeiten unverändert gegenüber Alpha K

## Prüfungen

| Prüfung | Ergebnis |
| --- | --- |
| `gradlew.bat build -x dist --console=plain` | Bestanden in 14 Sekunden |
| JUnit | 708 Tests in 125 Suites; keine Fehler oder übersprungenen Tests |
| Neue Store-Tests | Fünf Fälle für manuelle Namen mit aktuellen Titeln, Titel-/Profilsperren, leere gesperrte Titel und dauerhaftes Entsperren |
| Gezielter Server-/Clientlauf | `RP01`, `TXT01` und `UI-PEOPLE-LOCKS` bestanden; 48 Sekunden einschließlich Clientstart |
| `RP01` | Geschriebenen Brief schließen, erneut öffnen und verschicken |
| `TXT01` | Mehrseitigen Brief versenden, archivieren, empfangen, exportieren, importieren und erneut schreiben |
| `UI-PEOPLE-LOCKS` | Kennenlernen und Bearbeiten ohne automatische Häkchen; Titel aktualisiert sich; bewusste Sperren, Entsperren und Speichern beim Schließen funktionieren |
| Sichtkontrolle auf Deutsch | Briefbutton passt; farbige Chatmeldung und beide Sperrzustände im Personenbuch kontrolliert |
| Archivvergleich mit K | Nur Briefmeldungen, Personenstore, Kennenlernfenster, Personenbuch, zwei Sprachdateien und Versionsmetadaten geändert |
| Client-Manifest und übrige Assets | Unverändert; keine Test-/DevAuth-Klassen oder Debug-Marker in der JAR |
| Übersetzungen | Je 1.250 Schlüssel, gleiche Schlüsselmengen ohne Duplikate |
| Frühere Artefakte | Alpha A bis K und Original-Courier per SHA-256 unverändert |

Die vollständige Courier-Suite wurde für Alpha L nicht erneut ausgeführt.
Der letzte vollständige Lauf mit 100 bestandenen Fällen gehört zu
[Alpha K](0.1.17-k.md). Karten-, Tierregister- und Tierinfo-Klassen sind bytegleich
zu K. Die neuen Personenprüfungen verwenden einen isolierten Store.

Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11,
lokalem Paper 1.21.11 und unverändertem Courier 2.1.0.
Testserver und Testclient wurden nach dem Lauf beendet.
