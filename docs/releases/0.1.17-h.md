Getestet mit Java 21.0.10, Fabric Loader 0.19.3, Fabric API 0.141.4+1.21.11,
Xaero Minimap 25.3.12 und lokalem Paper 1.21.11 mit Courier 2.1.0.
Das Testprofil verwendet den [Mouse-Wheelie-Fix für Yarn-Dev-Clients](../dev-client/inventory-mousewheelie.md).
Diese lokale Fremdmod-Anpassung ist kein Bestandteil der OttoExtra-JAR.

Ein erster Glow-Testlauf scheiterte am Testaufbau: `Entity.setGlowing()` ist
auf der Clientseite ungeeignet, um ein serverseitiges Glow-Flag nachzubilden.
Der Test setzt jetzt gezielt das synchronisierte Flag. Der Produktionscode
wurde dadurch nicht verändert. Der erneute Lauf besteht einschließlich der
Prüfung, dass vorhandener Vanilla-Glow erhalten bleibt.

Die vollständige Courier-Suite, Tierübersicht und Minimap-Bedienung wurden für
diese Änderung nicht erneut ausgeführt. Shader-/Culling-Mod-Kombinationen und
eine manuelle Ottonien-Sitzung mit Alpha H sind nicht Bestandteil dieses Laufs.
Bestehende optionale-Mixin-/Testprofil-Auth- und Gradle-Deprecation-Meldungen
verhindern Build und die gezielten Clienttests nicht.
